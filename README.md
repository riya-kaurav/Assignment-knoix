# KoinX Tax Harvesting Tool

A responsive React app that helps users visualize tax savings through crypto tax loss harvesting.

## Setup Instructions

1. Clone the repo
   git clone https://github.com/YOURUSERNAME/koinx-tax-harvesting.git

2. Install dependencies
   npm install

3. Run the app
   npm run dev

4. Open http://localhost:5173

## Features
- Pre and After Harvesting capital gains comparison
- Real-time updates on holding selection
- Select all / deselect all holdings
- Tax savings banner
- Dark mode toggle
- Fully responsive

## Tech Stack
- React + Vite
- Tailwind CSS
- Mock APIs using Promises

## Assumptions
- All amounts are in USD.
- Mock data is used in place of real API calls.
- Short term and long term gains are calculated separately.
